# 🔁 HabitLoop

**Habit tracker with weekly AI-generated behavioral insights**

HabitLoop lets you check in on daily habits, add notes explaining what happened, and receive weekly reports generated by Gemini that describe behavioral patterns in your own words. It's a personal-use habit tracker, not a social platform.

---

## Features

- Daily check-ins with optional notes
- Streak tracking with a 1-day grace period
- Per-habit heatmap (12 weeks), day-of-week breakdown, 7/30/90-day completion rates
- Weekly Gemini insight: what went well, what held you back, one experiment to try
- In-app notifications for milestones and new insights
- Timezone-aware — "today" always resolves in the user's local timezone

## Architecture

```
Browser (React 19 + Zustand)
        │
    proxy.ts          — IP rate limiting, auth redirects
        │
Next.js API routes    — Zod validation, JWT session, Prisma queries
        │              ─── Google Gemini REST (server-only, key stays on server)
   PostgreSQL
```

Pages are server components. Client components handle interactions and call API routes directly. The proxy handles unauthenticated redirects and general rate limiting before any route handler runs.

|--------|-------|------|-------------|

## Security

- All API routes behind a 60 req/min/IP proxy rate limit
- Auth endpoints have additional per-IP and per-account rate limits
- Passwords hashed with bcrypt (cost 12)
- Sessions: HS256-signed JWT, `httpOnly; secure; SameSite=Lax`, 7-day expiry
- HTTP headers: CSP, `X-Frame-Options: DENY`, HSTS, `X-Content-Type-Options`
- Gemini API key never reaches the client (`import "server-only"` enforced)

## Engineering Notes

**Date strings over timestamps.** Check-ins store dates as `YYYY-MM-DD` in the user's local timezone. Avoids UTC drift — a check-in at 11 PM UTC+5 is correctly attributed to that day, not the next day in UTC. Trade-off: range queries use string comparison rather than timestamp arithmetic.

**Streak grace period.** One missed day doesn't break a streak. A two-day gap does. This is intentional — travel days and outliers shouldn't erase weeks of effort. The threshold is conservative enough that it still reflects real consistency.

**Gemini fallback.** The client tries `gemini-2.5-flash` first, then `gemini-2.5-flash-lite` after a 1-second delay. Each call times out at 15 seconds. Retries only on transient errors (429, 500, 503, network failure). Permanent failures (bad key, blocked prompt) fail immediately.

**In-memory rate limiting.** Uses module-level Maps — correct for a single process, won't coordinate across horizontal instances, resets on restart. Redis would be the right replacement if the app scaled out.
